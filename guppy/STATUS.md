# Status

Version 0.7 of the plugin is in production: the `[glotstats]` shortcode shows translators which popular plugins and themes of a locale still have untranslated strings. Work has started on a new view for translation editors that lists the subprojects with strings waiting for review. The development environment and project docs are ready; the next milestone is researching where translate.wordpress.org exposes that data.
